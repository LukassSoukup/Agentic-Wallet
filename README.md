# Agentic Wallet

A payment wallet for AI shopping agents. Every purchase an agent proposes passes through a deterministic **control and security layer** that answers *approve*, *decline* or *step up*, with reasons. A model may only make a decision more cautious, never less.

Status: **planning**. No production code yet.
